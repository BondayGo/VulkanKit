# Changelog

## 0.3.0 - 2026-10-28

- Bundle the loader companion next to the executable for machines without
  an installed SDK.
- Add the motor catalog for the test-bench rigs (`catalog.pdf`).
- Add `samples/settings.ini` for fleet-wide collector defaults.

## 0.2.0 - 2026-09-15

- Add `scripts/collect.ps1` for timestamped report collection.
- Add the optional C++ wrapper under `src/`.
- Store reports in UTF-8 to avoid garbled device names.

## 0.1.0 - 2026-08-02

- Initial bundle: upstream `vulkaninfo` build plus usage notes.
